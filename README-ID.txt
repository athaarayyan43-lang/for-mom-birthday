PANDUAN WEBSITE ULANG TAHUN MAMA

Project ini sudah disusun dari kode Gemini Canvas menjadi project React + Vite.

PUBLIKASIKAN DENGAN GITHUB + VERCEL
1. Ekstrak ZIP ini di laptop.
2. Buat akun GitHub jika belum punya, lalu buat repository baru bernama for-mom-birthday.
3. Unggah semua ISI folder mom-website ke repository (bukan ZIP-nya).
4. Buka Vercel dan masuk menggunakan GitHub.
5. Pilih Add New > Project, lalu pilih repository for-mom-birthday.
6. Framework Preset: Vite. Build Command: npm run build. Output Directory: dist.
7. Klik Deploy. Setelah selesai, Vercel memberi alamat website publik.

MASUKKAN KE GOOGLE SITES
1. Buka Google Sites > Sisipkan > Sematkan > By URL.
2. Tempel alamat publik Vercel, lalu klik Insert.

CATATAN PENTING
- File .tsx yang diunduh dari Gemini Canvas saja belum menjadi website siap-pasang. Project ZIP ini menambahkan file pendukung React/Vite.
- Tombol Ganti Foto pada kode saat ini hanya mengubah state halaman; foto bisa kembali seperti semula setelah halaman dimuat ulang.
- Fitur AI meminta API key dari pengunjung. Jangan menaruh API key rahasia di website publik; sebaiknya amankan melalui server atau nonaktifkan fitur itu sebelum dipublikasikan.
